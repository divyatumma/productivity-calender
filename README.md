### Productivity Range Calendar

A responsive, goal-driven calendar web app that allows users to select date ranges, track daily progress, and visualize productivity.

---

##  Features

### Date Range Selection
- Select start and end dates
- Automatically highlights selected range

###  Daily Status Tracking
- Mark each day as:
  - ✅ Completed
  - ⚠️ Partial
  - ❌ Missed
- Color-coded calendar visualization

###  Progress Tracking
- Displays progress like:
  - `You completed 7/10 days`
- Dynamic progress bar

### Notes System
- Attach notes to selected dates
- Real-time update

### Fully Responsive
- Desktop → Split layout (Calendar + Notes)
- Mobile → Stacked layout

---
